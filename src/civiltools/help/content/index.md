# civilTools Help

Welcome to **civilTools** — a standalone structural engineering application for
building design, analysis, and ETABS interoperability.

## System Requirements

| Component         | Minimum                 | Recommended             |
|-------------------|-------------------------|-------------------------|
| OS                | Windows 10 64-bit       | Windows 11 64-bit       |
| Python            | 3.12                    | 3.12+                   |
| RAM               | 4 GB                    | 8 GB+                   |
| GPU               | OpenGL 2.1              | OpenGL 4.5              |
| ETABS (optional)  | v18                     | v21+                    |

## About

civilTools is developed for structural engineers working with Iranian
building codes (Standard 2800, ABA, etc.) and CSI ETABS software.
